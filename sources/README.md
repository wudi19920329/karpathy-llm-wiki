# sources/ — 原始信源(只读)

放入原始材料:网页存档、PDF、论文、文章、图片。

规则:

- **只读、不可变**。这里的文件永不被改写。
- 网页优先用 `obsidian:defuddle` 抽取正文后再存档。
- 对每个重要信源,在 `pages/` 建一个 `type: source` 的页面记录元数据与要点。
  - **归档进本目录**的信源:源页 `source:` 指回此处文件。
  - **外部活源**(如兄弟子项目代码仓):**不复制进来**,源页 `source:` 直接指向其路径(如 `../boss`)并 pin 版本——纪律见 `../CLAUDE.md`「信源是子项目时」。
