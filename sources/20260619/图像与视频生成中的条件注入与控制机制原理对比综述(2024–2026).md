# 图像与视频生成中的条件注入与控制机制:原理对比综述(2024–2026)

## TL;DR
- **架构层面的范式转移已经完成**:扩散模型的骨干网络从 U-Net 全面转向 Diffusion Transformer(DiT),条件注入机制也随之从"U-Net + 独立 cross-attention"演进为"MMDiT 联合注意力 + token 序列拼接(in-context conditioning)"。FLUX.1 Kontext、OminiControl 等 2024–2025 方法证明:在 DiT 上,把参考图编码成 token 直接拼进注意力序列,往往比额外的 decoupled cross-attention 更简洁、更省参数。
- **注意力注入是统一所有控制机制的核心抽象**:文本通过 cross-attention(或 MMDiT 联合注意力)注入;参考图通过 decoupled cross-attention(IP-Adapter)或共享 KV/self-attention 注入;一致性与风格迁移通过 self-attention 共享(StyleAligned、MasaCtrl、ConsiStory、ReferenceNet)实现;视频时序一致性依赖 temporal attention 与跨帧注意力。它们的差异主要在于:注入到哪一层、是否需要训练、计算开销。
- **训练 vs 免训练(training-free)是关键工程取舍**:LoRA/IP-Adapter/ControlNet 需要训练但效果稳定、可复用;StyleAligned/MasaCtrl/ConsiStory/Prompt-to-Prompt 等注意力操纵方法免训练、即插即用,但稳定性较弱。实际生产中常组合使用(如 IP-Adapter + ControlNet + LoRA)。

## Key Findings

1. **从 U-Net 到 DiT**:U-Net 通过下采样/上采样和跳跃连接提供归纳偏置,条件通过 cross-attention(文本)和加性残差(ControlNet)注入。DiT(Peebles & Xie, 2023)用纯 Transformer 处理 VAE latent patch token,核心改动是用 adaLN(adaptive layer norm)注入时间步与类别条件,并因可扩展性(质量随 Gflops 单调提升)取代 U-Net。

2. **MMDiT 的双流/单流设计**:Stable Diffusion 3 的 MMDiT 为图像和文本使用独立权重,仅在注意力计算时拼接两种 modality 做联合(joint)全注意力,实现双向信息流。FLUX.1 进一步分成 19 个 double-stream 块(文本/图像分开权重)+ 38 个 single-stream 块(共享权重,attention 与 MLP 并行计算)。这与 U-Net 时代"文本→图像单向 cross-attention"有本质区别。

3. **文本编码器的分工**:CLIP text encoder(对比学习,擅长短语义/视觉概念)与 T5/MLLM(纯文本大语料,擅长长文本/复杂指令)各有所长。SD3/SD3.5 用 CLIP-L + OpenCLIP-G + T5-XXL 三编码器;FLUX 仅用 T5 做序列文本,CLIP 仅做 pooled embedding 用于调制;HunyuanVideo 用 MLLM(decoder-only)替代 T5 以获得更好的图文对齐。

4. **参考图注入的两代范式**:U-Net 时代以 IP-Adapter 的 decoupled cross-attention 为主(为图像特征单独加一组 K/V,与文本注意力输出相加),仅 22M 参数即可媲美全量微调;FaceID/InstantID 用人脸识别 embedding 替代 CLIP 并叠加额外空间控制。DiT 时代转向 in-context token 拼接(FLUX.1 Kontext、OminiControl)。

5. **视频生成的条件控制**:图生视频(I2V)通过首帧 latent 通道拼接(Wan、HunyuanVideo-I2V)或时空注意力(ConsistI2V)注入;角色动画用 ReferenceNet(对称 U-Net,把参考特征拼进 self-attention 的 K/V)保持外观一致;时序一致性靠 temporal attention、跨帧注意力、optical-flow guided attention。

## Details

### 一、Transformer / DiT 架构在生成中的作用

**U-Net 到 DiT 的演进。** 早期扩散模型(DDPM、Stable Diffusion 1.x/2.x)使用卷积 U-Net 作为去噪骨干,其编码器下采样捕捉全局语义、解码器加跳跃连接恢复细节,卷积归纳偏置天然适合去噪。但 U-Net 难以扩展到高分辨率与超大参数。DiT(*Scalable Diffusion Models with Transformers*,Peebles & Xie, 2023)在 latent diffusion 框架内,用 ViT 风格 Transformer 处理 VAE 压缩后的 patch token。其关键发现是:扩散模型质量随 Transformer 前向计算量(Gflops)单调提升——这正是 U-Net 不具备的可扩展性。DiT 论文的核心结论之一是,条件注入机制(time step、class label)用带 adaLN 的 ViT 块效果最好,adaLN 层调制残差连接前的激活并初始化为恒等函数,"仅改变条件注入机制就能在 FID 上带来巨大差异"。

**Token 化方式。** 图像:VAE encoder 把图像压缩到 latent(SD3 用 16 通道 VAE),再切成 patch token,加位置编码。视频:Sora 把视频压缩到时空 latent 后提取"spacetime patches"作为 transformer token,"图像即单帧视频";Kling、Vidu 等同样用 3D VAE 把整段视频压成时空 patch。FLUX/HunyuanVideo 用 factorized 3D RoPE,每个 latent token 用其时空坐标 (t,h,w) 索引。

**MMDiT 的双流/单流。** SD3 的 MMDiT(Esser et al., 2024)对文本和图像 embedding 使用两套独立权重(因为两种 modality 概念差异大),仅在注意力时拼接做 joint attention。与 PixArt-α 等单向 cross-attention DiT 不同,MMDiT 让信息在文本与图像分支间双向流动,显著改善图文对齐尤其是排版(typography)。SD3.5 升级为 MMDiT-X:加入 QK-normalization 提升训练稳定性,并在前 12 层加 dual attention 块。FLUX.1 把架构拆成 19 个 double-stream 块(文本/图像分开 Q/K/V 投影与调制层)+ 38 个 single-stream 块(共享投影、attention 与 MLP 并行计算,丢弃文本 token 后解码图像 token)。double-stream 让两种 modality 各自特化表示,single-stream 共享权重提升参数效率;两者都用 multi-modal attention 在拼接的文本+图像 token 上做联合自注意力。

### 二、CLIP 及文本/图像编码器

**CLIP 的角色。** CLIP(Radford et al., 2021)通过对比学习把文本与图像对齐到同一 latent 空间。Stable Diffusion 用 frozen CLIP 的 un-pooled text embedding 作 cross-attention 条件;DALL-E 2 用 CLIP image embedding 加 prior。CLIP text encoder 擅长编码短的、常见的英文概念,产生更密集、更局部的注意力。

**CLIP vs T5 vs MLLM。** T5 在 800GB C4 纯文本语料上训练(最大 11B),擅长长文本与复杂指令,产生更分散、更上下文化的注意力。Imagen 早期就发现:扩大冻结语言模型 text encoder 的规模显著提升图文对齐。实践中常组合:有研究显示 CLIP+T5 显著优于单用任一者,因为兼得 CLIP 的图文配对预训练与 T5 的长文本编码能力。SD3/SD3.5 用三编码器(CLIP-L + OpenCLIP-G + T5-XXL),沿序列维拼接两个 CLIP embedding 与 T5 embedding;FLUX 仅把 T5 用于文本分支,CLIP 仅作 pooled embedding 用于 scale/shift 调制。HunyuanVideo 用 decoder-only MLLM(经视觉指令微调)替代 T5,因其图文对齐更好、细节描述与复杂推理更强,并加一个双向 token refiner 增强文本特征。

**embedding 如何注入。** 文本 embedding 在 U-Net 时代通过 cross-attention(文本作 K/V,latent 作 Q)注入;在 MMDiT 中作为 token 与图像 token 拼接后做联合注意力。pooled 全局 embedding 则常通过 adaLN/调制(投影到时间步条件上)注入。

### 三、参考图机制(Reference Image / Image Prompt)

**IP-Adapter(核心:decoupled cross-attention)。** IP-Adapter(Ye et al., 2023,arXiv:2308.06721)用 CLIP image encoder 提取参考图特征,经小投影网络变成与文本特征同维的序列;关键设计是 decoupled cross-attention:为 U-Net 每个 cross-attention 层额外加一组只处理图像特征的 K'/V',输出 Z' = Attention(Q,K,V) + λ·Attention(Q,K',V'),仅训练新增的 K'/V' 投影,base 模型冻结。论文原文表明:"an IP-Adapter with only 22M parameters can achieve comparable or even better performance to a fully fine-tuned image prompt model"(仅 22M 参数即可媲美甚至超过全量微调的图像提示模型)。优点:轻量、可复用(可迁移到同 base 微调的其他模型)、与文本及 ControlNet 兼容。

**变体。** IP-Adapter Plus 用更多/更细的图像 token 提升细节;IP-Adapter-FaceID 用人脸识别模型的 face ID embedding 替代 CLIP image embedding,并加 LoRA 提升 ID 一致性;FaceID-PlusV2 同时用 face ID embedding(身份)+ 可控 CLIP image embedding(面部结构)。InstantID(Wang et al., 2024,arXiv:2401.07519)结合三要素:捕捉身份语义的 ID embedding、带 decoupled cross-attention 的轻量适配模块、以及叠加空间控制的 IdentityNet(把人脸与 landmark 图作弱空间条件),单张人脸图即可零样本保持身份且保留文本可编辑性,优于 PhotoMaker 与 IP-Adapter-FaceID 的文本控制退化问题。PuLID 是更新的同类方法。

**ReferenceNet / Reference-only。** ReferenceNet(Animate Anyone,Hu et al., 2023,arXiv:2311.17117)引入一个与去噪 U-Net 对称的可训练副本来编码参考图空间细节,在每个对应层通过 spatial self-attention 注入:把参考特征 z_r 与去噪 latent z_i 在 self-attention 的 K/V 上拼接(K'=W^K[z_i,z_r],V'=W^V[z_i,z_r]),从而严格保留参考图的身份与背景。这建立在 MasaCtrl 与 Reference-only ControlNet 操纵 self-attention 的思路上,比 ControlNet 的加性残差更能保留细节,广泛用于 MagicAnimate、MagicPose 等角色动画。

**DiT 时代的 in-context 范式(2024–2025 最新)。** 由于 MMDiT 用联合注意力而非独立 cross-attention,参考图注入转向"token 拼接进序列"。**OminiControl**(Tan et al., NUS,arXiv:2411.15098,ICCV 2025)三大设计:(1)复用 DiT 自身 VAE encoder 把条件图编码到同一 latent 空间,论文称仅"~0.1% additional parameters"(在 FLUX.1 上的具体设定为约 0.4% 额外参数,以 LoRA 微调实现);(2)把条件 token 与图像 token 拼成统一序列由原 DiT 块的 multi-modal attention 处理,而非 ControlNet 式空间特征相加;(3)动态位置编码适配空间对齐(如 Canny)与非对齐(如 subject-driven)任务,并配套 **Subjects200K** 数据集——论文描述为"a diverse collection of over 200,000 identity-consistent images"(超过 20 万身份一致图像,其中 3 万余条主体描述由 GPT-4o 生成)。**FLUX.1 Kontext**(Black Forest Labs,2025,arXiv:2506.15742)用"sequence concatenation"统一局部编辑与 in-context 生成:参考图经冻结 FLUX auto-encoder 编码成 context token 喂入视觉流,用 3D RoPE 给 context token 加一个常数时间步偏移以干净分离 context 与 target;无独立 cross-attention,context token 与噪声/文本 token 一起参与联合全注意力。代价是上下文窗口约翻倍(≈2× 计算),但不增加新参数(从 FLUX.1 12B 全量微调 + LADD 蒸馏);论文称采用 LADD 后"1024px images generated in 3–5 seconds—enabling rapid feedback in creative workflows",并配套含 1,026 个图文指令对的 KontextBench 基准。**IP-Adapter 也被移植到 FLUX**(InstantX FLUX.1-dev IP-Adapter):在全部 57 个块(38 single + 19 double)加新的图像注意力处理器,用 SigLIP-so400m 编码 + 2 层 MLP 投影成 128 个图像 token——仍是 decoupled 图像注意力路径求和进联合注意力,与 Kontext/OminiControl 的纯序列拼接不同。

**视频中的参考图/首帧控制。** I2V 主流是把首帧 latent 与噪声 latent 在通道维拼接(Wan2.1 扩展到 I2V、FLF2V、depth-to-video 等,通过拼接 conditional 与 mask 通道;HunyuanVideo-I2V 同架构加条件模块)。ConsistI2V 用首帧时空注意力 + FrameInit(用首帧低频成分初始化噪声)增强一致性。HunyuanVideo-Avatar、HunyuanCustom 在 base DiT 上加身份/音频条件模块支持多条件。

### 四、LoRA(Low-Rank Adaptation)

**原理。** 对权重 W,LoRA 冻结 W 而学习低秩增量 ΔW=BA(B∈R^{d×r},A∈R^{r×d},r≪d),仅训练 A、B,大幅减少可训练参数,基于"预训练模型有低内在维度"的观察。

**与其他定制方法对比。** DreamBooth 全量微调 U-Net(常配 LoRA 降参),保真度最高但存储低效(每概念一个新模型);Textual Inversion 只学一个新 token 的 embedding 向量,文件极小但保真度有限;LoRA 插入低秩层,训练快、文件小、可分享与叠加,是风格/角色/概念定制的主流。就训练耗时而言,优化式方法成本明显高于免训练方法:ConsiStory(Tewel et al., NVIDIA, arXiv:2402.03286v2)在 H100 上的 time-to-consistent-subject(TTCS)为 32 秒("achieved the fastest TTCS result, at 32 seconds"),而相关工作(Storybooth, arXiv:2504.05800)指出 DreamBooth-LoRA 与 Textual Inversion 分别"require approximately 5 min and 7.5 min respectively"(约 5 分钟、7.5 分钟)。

**多 LoRA 融合。** LoRA Merge 线性加权合并多个 LoRA(W'=W+Σw_i B_i A_i),简单但 LoRA 过多会失稳、且忽略生成过程交互;LoRAHub、ZipLoRA 学系数矩阵融合;Multi-LoRA Composition(Zhong et al., 2024)提出 LoRA Switch(每步切换激活单个 LoRA)与 LoRA Composite(每步聚合多 LoRA 输出);MultLFG 用频域引导自适应融合;FreeFuse 在测试时用注意力图自动 masking 融合多主体 LoRA。

**视频中的 LoRA。** Wan、HunyuanVideo 等视频 DiT 同样支持 LoRA(社区有大量风格/动作 LoRA),用于在视频模型上做轻量风格与概念定制。

### 五、注意力注入机制(重点)

**(1)Cross-attention 注入条件。** 标准机制:latent 作 Q,条件(文本/图像)作 K/V,输出 = softmax(QK^T/√d)V,把条件信息按空间相关性注入生成 latent。在 MMDiT 中升级为联合注意力(文本+图像 token 拼接后全注意力)。

**(2)Decoupled cross-attention(IP-Adapter 核心)。** 为图像特征单独加一组 K'/V',与文本 cross-attention 输出相加:Z'=Attention(Q,K,V)+λ·Attention(Q,K',V')。λ 控制图像影响强度。优点:文本与图像条件解耦、互不干扰、可独立加权。InstantStyle 在此基础上发现 SDXL 中仅 up_blocks.0.attentions.1 与 down_blocks.2.attentions.1 两层负责风格/布局,故只把图像特征注入这些"风格块"即可隐式解耦风格与内容,并用 CLIP 特征相减(图像特征减内容文本特征)进一步去除内容泄漏。

**(3)Self-attention 注入 / 共享 KV。** 用于参考图、风格迁移、一致性生成,多为免训练:
- **MasaCtrl**(Cao et al., 2023):把 self-attention 转成 mutual self-attention,让目标图的 Q 去查询源图的 K/V,实现非刚性编辑下的内容一致;并用 cross-attention map 提取 mask 做 mask-guided 控制以分离前景背景。
- **StyleAligned**(Hertz et al., 2024):通过最小化的"attention sharing"——目标图对其 Q/K 施加 AdaIN(用参考图的 Q/K),再做共享注意力(目标特征同时被目标 V_t 与参考 V_r 更新)——在一批生成图间保持风格一致,免训练、可与 ControlNet/DreamBooth/MultiDiffusion 组合。
- **Reference-only ControlNet**:把参考图特征直接拼进 self-attention,无需训练额外模型。
- **ConsiStory**(Tewel et al., NVIDIA, 2024,arXiv:2402.03286):Subject-Driven Self-Attention(SDSA)让每张图通过扩展 self-attention 去 attend 其他帧中主体的 patch(共享主体的 K/V),配合 correspondence-based feature injection 保持主体一致;再用 vanilla query 注入 + KV dropout 恢复布局多样性。NVIDIA 称其约比当时 SOTA 方法快 20 倍("roughly twenty times faster than the current state-of-the-art methods")。
- **StoryDiffusion**(2024):Consistent Self-Attention 跨批次图像采样以保持角色一致,用于长程故事/漫画生成。

**(4)Attention manipulation / attention map 控制。** 
- **Prompt-to-Prompt**(Hertz et al., 2022):cross-attention map 决定空间布局与几何;通过注入源图的 cross-attention map(word swap 时固定 map、refinement 时冻结旧 token 注意力并放行新 token、re-weighting 时缩放特定词注意力)实现免训练、免 mask 的语义编辑。结构在扩散早期步即确定,故注入早期 attention 即可保留构图。
- 相关方法:Attend-and-Excite(放大被忽视主体 token 的注意力激活)、Structured Diffusion、Directed Diffusion 等。

**(5)视频时序注意力。** 多数视频扩散在 U-Net 加 temporal attention 模块(2D+1D:对每个空间位置沿时间轴做注意力)。变体:temporal attention(同位置跨帧)、full spatio-temporal attention(所有帧所有 patch,如 CogVideoX、HunyuanVideo 的 unified full attention)、causal/sparse-causal attention。免训练时序一致性:Text2Video-Zero(跨帧注意力)、FateZero(融合 inversion 与生成的注意力图)、Flatten/Fresco(optical-flow guided attention)、TokenFlow(跨帧特征传播)、AnyV2V(注入源视频 temporal self-attention 的 Q/K 保持运动);RefDrop 用 rank-1 系数的 RFG 层替换 self-attention 灵活控制一致性,适用 U-Net 与 transformer。

**(6)对比维度。** 注入位置:cross-attention(文本/图像条件)vs self-attention(一致性/风格)vs temporal attention(时序)。加权:λ 标量(IP-Adapter)、AdaIN(StyleAligned)、rank-1 系数(RefDrop)、注意力图缩放(P2P)。训练 vs 免训练:IP-Adapter/ReferenceNet/ControlNet/LoRA 需训练;MasaCtrl/StyleAligned/ConsiStory/P2P/AnyV2V 免训练。计算开销:免训练方法零训练成本但增加推理时注意力计算(共享 KV 使序列变长);in-context 拼接(Kontext)上下文翻倍约 2× 计算。

### 六、结构控制:ControlNet(作为对照)

ControlNet(Zhang et al., 2023)冻结 base、复制其编码块为可训练副本,用 zero convolution(1×1 卷积权重与偏置初始化为 0)连接,使训练初期不破坏 base、逐步学习边缘/姿态/深度/分割等空间条件,以加性残差注入。DiT 时代被移植:FLUX ControlNet(XLabs/InstantX,2024)复制少量 MMDiT multi-stream 块作控制分支、残差加回主流(据第三方论文 CannyEdit, arXiv:2508.06937 描述,XLabs Canny 变体复制约 2 个 multi-stream 块);BFL 官方 FLUX.1-Depth/Canny-dev 则是全 12B 模型经输入拼接注入(更重);Stability AI 为 SD3.5 Large 发布 Blur/Canny/Depth 三个 ControlNet(8B 参数级)。

### 七、机制组合

生产流水线常组合:IP-Adapter(参考图/身份)+ ControlNet(姿态/深度结构)+ LoRA(风格/角色)+ 文本 prompt;StyleAligned 可叠加 ControlNet/DreamBooth-LoRA;InstantID = ID embedding + decoupled cross-attention + IdentityNet(空间);角色动画 = ReferenceNet(外观)+ Pose Guider(姿态)+ temporal attention(时序)+ CLIP image encoder(语义)。decoupled cross-attention 的"可加性"是这些组合得以成立的关键。

## Recommendations

**按场景选择机制:**
1. **单图风格/角色定制,追求保真**:用 LoRA(或 DreamBooth-LoRA),若需多概念用 ZipLoRA 或 Multi-LoRA Composition;阈值——若每概念可接受约 5 分钟训练且需复用,选 LoRA;若要秒级零样本(数十秒内),转向免训练注意力共享(ConsiStory/StyleAligned)。
2. **参考图/身份保持(零样本)**:U-Net 选 IP-Adapter(通用)/InstantID(人脸);DiT/FLUX 选 in-context 方法(FLUX.1 Kontext、OminiControl)或 FLUX IP-Adapter。基准——身份相似度 vs 文本可编辑性的权衡,InstantID 在人脸场景同时兼顾两者。
3. **风格迁移免训练**:StyleAligned(批量风格一致)或 InstantStyle(只注入风格块 + CLIP 特征相减防内容泄漏)。
4. **多图/故事一致性**:ConsiStory(主体一致 + 布局多样)、StoryDiffusion(长程);需姿态控制时叠加 ControlNet。
5. **结构控制**:ControlNet(边缘/深度/姿态);DiT 上用 FLUX/SD3.5 ControlNet 或 OminiControl(额外参数仅约 0.1%–0.4%)。
6. **视频**:I2V 用首帧通道拼接(Wan/HunyuanVideo);角色动画用 ReferenceNet + Pose Guider;时序一致性优先 full spatio-temporal attention 的现代 DiT(HunyuanVideo、CogVideoX),编辑用 AnyV2V/Flatten。

**改变建议的触发条件:** 若骨干迁移到 MMDiT/DiT,应放弃 U-Net 式 decoupled cross-attention 的默认假设,优先评估 token 拼接(in-context)方案——它在 DiT 上参数更省(OminiControl 约 0.1%–0.4%)、与联合注意力天然契合。若推理延迟敏感,避免上下文翻倍的 Kontext 式拼接,改用轻量 adapter。

## Caveats
- **架构细节披露有限**:Sora、Kling 等闭源模型的架构多为逆向推测(spacetime patch、3D VAE、DiT),OpenAI 技术报告明确不含实现细节;FLUX.1 Kontext 论文偏"评测报告",训练数据与完整超参为高层概述。
- **FLUX ControlNet 无官方论文**:XLabs/InstantX 实现的内部架构(如"复制 2 个 multi-stream 块")源自第三方论文(CannyEdit, arXiv:2508.06937)描述,不同变体深度/规模可能不同。
- **SD3.5 ControlNet 日期**:Stability 官方与 ComfyUI 博客指向约 2024 年 11 月底,部分二手站点误作 10/26。
- **数值口径差异**:不同来源对训练耗时与加速比的口径不一(例如 ConsiStory 官方称"约 20 倍"于当时 SOTA,而非笼统的 8–14 倍;DreamBooth-LoRA 训练时长不同来源在 4.5–5 分钟间);本文以原始论文/项目页口径为准。
- **性能宣称需审慎**:各模型官方的"超越竞品"多基于自家人类偏好评测,存在选择性;免训练注意力方法稳定性弱于训练式,失败案例(前景背景混淆、内容泄漏)常见。
- **快速演进领域**:本综述覆盖到 2026 年初,DiT 条件注入仍在快速变化,具体方法的相对优劣可能随新模型发布而改变。
