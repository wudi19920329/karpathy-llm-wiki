# F2 — 批量改名工具

## 摘要 / Summary

**F2**（`ayoisaiah/f2`）是一个用 **Go** 写的跨平台命令行**批量重命名**工具:正则 `find → replace`、自增序号、内置/EXIF/日期变量、CSV 驱动改名,带**安全检查**(冲突检测 + 默认不覆盖)与**撤销**。本机已装在 `C:\Users\admin\go\bin\f2.exe`(版本 **v2.2.2**,纯 Go,`go install` 而来,见 [[本机开发环境]])。在「一批文件要按规则统一改名 / 编号」时用它,而不是手写脚本。

- 手册:https://f2.freshman.tech · 仓库:https://github.com/ayoisaiah/f2
- 安装:`go install github.com/ayoisaiah/f2/v2/cmd/f2@latest`(落在 `GOPATH\bin`)

## 心智模型 / Mental model

> [!important] 默认 dry-run,`-x` 才落盘
> 不带 `-x/--exec` 时 F2 **只打印预览表(ORIGINAL → RENAMED → STATUS)不动磁盘**。确认预览全 `ok` 后,**同一条命令加 `-x`** 执行。改错了用 `-u/--exec` 撤销(见下)。这套「先预览后提交」是 F2 的核心安全模型——养成**先空跑**的习惯。

工作流:`f2 <flags> <路径>` → 看预览 → 加 `-x` 提交 → (如需)`f2 -u -x` 回滚。
不给路径则只搜当前目录;给目录则搜该目录(**默认不递归**,递归用 `-R`)。

## 核心标志 / Core flags

| 标志 | 作用 |
|------|------|
| `-f, --find` | 匹配用的**正则**(RE2 语法);默认 `.*` 匹配整个文件名 |
| `-r, --replace` | 替换串;支持捕获组 `$1`、内置变量、EXIF/日期变量 |
| `-x, --exec` | **执行**改名(否则只 dry-run 预览) |
| `-u, --undo` | 撤销当前目录上一次改名(配 `-x` 落盘) |
| `-s, --string-mode` | 把 `-f` 当**字面字符串**而非正则 |
| `-e, --ignore-ext` | 匹配/替换时**忽略扩展名**,自动保留 `.png` 等 |
| `-R, --recursive` | 递归子目录(配 `-m/--max-depth` 限深) |
| `--sort natural` | 按**自然序**排序(`2 < 10`,比默认字典序更符合直觉) |
| `-F, --fix-conflicts` | 自动用 `(1)`/`_01` 等规则消解命名冲突 |
| `--allow-overwrites` | 允许覆盖已存在文件(**危险,会丢数据**) |
| `-d/-D` | 包含目录 / 仅改目录 |
| `-t, --target-dir` | 改名同时移动到目标目录 |

## 替换变量 / Replace variables

- **自增序号**:`{%03d}` → `001,002,…`(`%d` 是 Go 格式串,`03` 控制零填充位数)。配 `--sort` 决定编号顺序。
- **正则捕获组**:`-f '(\d+)_(.+)' -r '$2_$1'` 用 `$1 $2` 回填。
- **日期/时间变量**:`{YYYY}-{MM}-{DD}`、`{H}{MM}{ss}`,配 `--dt` 设默认时间源、`--timezone` 指定 IANA 时区。
- **EXIF 变量**:`{xt.DateTimeOriginal.dt.YYYY}` 等(底层调 exiftool,照片整理常用)。
- **CSV 驱动**:`--csv file.csv` 按表内容改名。
- 完整变量目录见手册;本页只列已验证常用项。

## 实战配方:整目录顺序编号 / Recipe: sequential numbering

把一个目录里所有 PNG 改成 `001.png … NNN.png`(已在本机验证):

```bash
# 1) 先空跑预览
f2 -f '.*' -e -r '{%03d}' --sort natural "D:/path/to/dir"
# 2) 预览全 ok 后,同命令加 -x 执行
f2 -f '.*' -e -r '{%03d}' --sort natural -x "D:/path/to/dir"
# 3) 改错了就撤销
f2 -u -x "D:/path/to/dir"
```

- `-e` 让 `.png` 自动保留,只需写 `{%03d}`。
- 加固定前缀:`-r '001-{%03d}'` → `001-001.png …`。
- `--sort natural` 保证 `02_… < 10_… < 22_…`;ASCII 文件名排在 CJK(中文)文件名之前。

## 安全 / Safety

- **默认 dry-run**,不会误改。
- **默认不覆盖**已存在文件;目标重名会标 `STATUS` 非 `ok`,需 `-F` 消解或 `--allow-overwrites`(慎用)。
- `-u/--undo` 仅回滚**当前目录的上一次**操作。
- `F2_DEFAULT_OPTS` 环境变量可设默认选项(如 `export F2_DEFAULT_OPTS='--exec --ignore-ext'`)——⚠️ 若默认开 `--exec` 会**跳过 dry-run**,本机未设,保留先预览习惯。
