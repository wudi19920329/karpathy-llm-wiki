# 抖音科普视频生产流水线

## 摘要 / Summary

「MG 动画 + 实操录屏」形态科普视频（对标 → [[对标账号-小白debug拆解]]）的**程序化生产流水线**：脚本为唯一数据源，Remotion 渲染、逐句 TTS 对齐字幕、LoRA 看板娘 + 程序化叠字出封面。与 [[剧本到AI漫剧生产流水线]]（叙事漫剧）互为姊妹篇——本条线是**信息密度型**内容，动画由数据驱动而非逐镜生成。目标：单期人工 ≤1.5h。状态 draft：待首支成片（E001）端到端验证后转 stable。

## 流水线 / The pipeline

```
选题(热点雷达) → script.md(逐句口播+分镜标记) → TTS 逐句合成 → timeline.json → Remotion render → 封面(LoRA立绘+叠字) → 发布
```

1. **脚本即数据源**：口播稿逐句编号，每句带分镜标记（`[卡:]` 大字卡 / `[图解:]` 概念动画 / `[录屏:]` 实操）。TTS、字幕、场景切分全部从这一份文件派生。
2. **逐句 TTS = 免费的字幕时间轴**：GPT-SoVITS 按句合成，每句 wav 时长即字幕 cue 时长，**无需 whisper 强对齐**。克隆音色只用自己的声音（合规）。⚠️ Blackwell 卡（RTX 5090 系）须用 `-nvidia50` 整合包（普通版 torch 不支持 CC 12.0），见 [[本机开发环境]]。
3. **Remotion 数据驱动渲染**：视频 = `timeline.json`（场景序列 + 字幕轨 + 音频路径），组件库固化风格（网格底/大字卡/图解盒箭头/发光高亮录屏框/硬字幕）；风格改主题 tokens，不碰单期数据。素材须置于 `public/` 经 staticFile 引用。

> [!warning] Remotion 国内网络坑（2026-07-09 实证）
> 首次渲染自动从 `storage.googleapis.com` 下载 Chrome Headless Shell，国内直连**卡死**（进程低 CPU 假活）。解法：从 npmmirror 的 chrome-for-testing 镜像手动下载同版本 zip，解压到 `node_modules/.remotion/chrome-headless-shell/win64/`，并在 `remotion.config.ts` 用 `Config.setBrowserExecutable()` 钉死路径。另：Windows 杀渲染进程只杀外层 shell 会留孤儿 node 子进程，会互抢下载锁、删已部署二进制——需按 PID 清理。
4. **封面 = LoRA 角色 + 程序化叠字**：中文大字**不交给扩散模型**（可控性差），ComfyUI 出看板娘立绘 → 抠底 → Remotion Still 模板叠字。角色资产走 [[剧本到AI漫剧生产流水线]] S2-S4（设定表→数据集→打标→[[Flux-LoRA-ai-toolkit训练实战]]）。
5. **热点雷达**：每日 RSS 摘要（smol.ai）+ 每周官方 changelog + 对标号监控 → 选题库打分（热度×2+易做+素材重合）；重大发布走 48h 快评通道（砍动画，录屏+字幕直出）。
