# 角色 LoRA 数据集构建

## 摘要 / Summary

把单张/少量参考图,扩充并筛选成一套能训出**身份稳定、又能换姿势换服装**的角色 [[LoRA]] 训练集。三篇 2026 指南交叉综合的结论高度一致:**先以面部特写锚定身份,但训练比重要向全身倾斜;数量小而精(15–30 张);背景要多样而非纯色;单图扩充首选 [[Flux-Kontext]] / [[Qwen-Image-Edit]]**。本页是数据集层面的方法论;训练超参与调试见 [[Flux-LoRA-ai-toolkit训练实战]]。

## 核心结论 / Key points

### 1. 景别优先级:收集顺序 vs 训练比重是两回事

- **收集/锚定顺序**:面部特写 → 半身 → 全身。特写是身份锚点、最好拍、学得最快最准(脸几乎占满画面);全身最难、最易漂移。
  - ⚠️ 注意区分:这里是**数据集收集顺序**(特写优先);[[ComfyUI-角色多镜头一致性工作流|生产时的生成顺序]]反过来是**全身设定表优先**——不同活动,别对撞(见对方页 "澄清 X-1")。
- **景别对应英文** close-up(特写)、bust/upper-body(半身)、cowboy shot(七分身,膝盖以上)、full body shot(全身)。
- "只有特写 → 全身出图脸漂移/畸形;只有全身 → 脸像素太少学不到细节"是核心矛盾,解法是**控制性多样 + 比重加权**。

> [!warning] 矛盾澄清 #1(最关键):配比"特写最多"还是"全身最多"?
> 两篇给的数字**乍看完全相反**,实为不同量纲:
> - 〔LoRA 训练集制作完全指南〕:`4:3:1`(特写:半身:全身),**指原始图像张数**——特写好拍、按张数最多,全身约 10–30%。
> - 〔构建角色 LoRA 数据集〕:`1:2:3`(特写:中景:全身),**指 Kohya 重复次数(repeat)权重**,使约 50% 训练视图来自全身;并明确警告"**完全平衡的 1:1:1 不会训出好结果**"。
>
> **调和**:原始张数可以特写多、全身少;再用 **repeat 次数把全身比重拉到 ~50%**(全身脸小、学得慢,需要补)。
> **推荐基线**:张数上特写/半身/全身约 `4:3:3`~均衡;Kohya 文件夹用 `3_closeup / 6_mid / 9_fullbody`(下划线前数字=repeat)实现 1:2:3 权重。**若全身需要极高 repeat 才够,应直接补更多全身图,而非硬加 repeat**(否则锁死姿势/服装)。

| 景别 | 身份贡献 | 学习速度 | 数据集角色 |
|---|---|---|---|
| 面部/头部特写 | 最高(脸像素最多) | 最快最准 | 身份上限锚点;脸占画面 ~40–60% |
| 半身(腰/胸以上) | 中(脸仍较大) | 中 | 承上启下,桥接脸与身体/服装 |
| 全身立绘 | 低(脸像素少) | 最慢 | 比例/姿势泛化;缺失则全身崩坏 |

### 2. 数量:小而精,过多反伤

- **甜点 15–30 张**(20–25 最佳);Flux 比 SD1.5/SDXL 省图很多(Flux ~25–30 vs SD1.5 70–200)。
- 最低约 10 张可用(Flux 甚至能用 attention masking 从单图起);**超过约 40–50 张而多样性没同步提升 → 过拟合**(失焦、塑料感、姿势锁定)。质量与多样性 > 原始张数。

### 3. "训练目标一致,其余全部多样"(黄金原则)

- 要学进 LoRA 的(脸、发型、瞳色、标志服装)**保持一致**;不想被锁死的(姿势、表情、背景、临时服装、光照、角度)**尽量多样**。
- **任一非身份属性最多出现在 3–6 张图**,否则会被"烘焙"进 LoRA(如"背面总配原服装"→ 想要背面就出原服装的耦合污染)。
- 角度覆盖正面/45°/纯侧/背面 + 俯仰;表情 ≥4 种;光照 ≥3 种。

### 4. 背景范式转变:纯色 → 多样

> [!info] 旧观念已被推翻
> 旧主流:纯色/去背景(rembg),让模型只学脸。**2025+ 新主流(RunDiffusion 等)**:多样背景"教会模型**分离**主体,而非记住固定环境"。
> **陷阱**:纯黑/纯白背景会被模型学进去(kohya musubi-tuner #227);相同背景重复多张也会被烘焙。折中——背景多样但不喧宾夺主、不含其他角色,必要时用 masked training。

### 5. 单图/少量扩充:工具代际(弱→强)

1. **Reference-only ControlNet**(最早)——多角度一致性差,仅轻度风格参考。
2. **[[IP-Adapter]] / IP-Adapter-FaceID**——CLIP/人脸嵌入迁移,相似度中等,会泄漏风格。
3. **InstantID**(单图零训练)——正面脸最佳,全身弱、遮挡易漂移。
4. **[[Flux-Kontext]] / [[Qwen-Image-Edit]]-2509/2511(当前最强)**——基于参考图编辑而非从头生成,身份一致性显著领先。典型流程:1 张种子图 → 20–50 条姿势/服装/背景/表情 prompt → 批量生成 → 人工挑 30+ 张。
   - ⚠️ Kontext **超过约 6 次链式编辑后**会累积退化,应**从原始种子单步生成各变体**,而非在已编辑图上反复编辑。
   - 机制原理见 [[扩散模型条件注入机制综述]]。

### 6. 打标铁律:Flux 用自然语言,"没描述的会被绑定"

> 打标的通用概念(定义、WD14/BLIP 方法对比、格式示例)见 [[LoRA打标]];本节是 Flux 角色 LoRA 场景下的进阶铁律与矛盾澄清。

- **Flux 偏好自然语言长 caption**(走 T5 编码器);SD1.5/SDXL 偏 booru tag(WD14)。进阶做法:**WD14 + 自然语言双标**,喂饱 CLIP-L 与 T5 两个编码器。
- **黄金法则**:**标注你想可变的(服装/姿势/背景/表情/景别);省略你想锁进触发词的(脸型/瞳色/标志发型)**。"触发词 = 你没标注的那部分"。把这条固化成硬约束的一个中文打标 agent(z-image 底模)见 [[z-image-agent打标工程师]]。
- **按景别明确打标**("close-up portrait" / "full body standing"),让构图成为可控轴,而非与身份纠缠。
- **触发词**:罕见乱码 token(`p3rs0n`、`sh4d0wh34rt`、`eksray`)+ 类别词(woman/man/character),放 caption **开头**——但 caption 整体仍须是自然语言句子(**"首位"≠"只有一个孤立触发词"**,详见 [[Flux-LoRA-ai-toolkit训练实战#触发词]] 的来源分歧);**不用角色真名**(防 base 模型同名知识漏入)。⚠️ 注意 [[z-image-agent打标工程师]] 那份 prompt 的**示例**用了真名 `diaochan`——那只是示例、触发词仍由用户定,别照抄真名,按本条用罕见 token。
- 自动打标([[JoyCaption]] / Florence-2 / WD14 / BLIP)**必须人工复核**——一张错标即可教坏 LoRA。按场景选哪个工具(含 2026 新增的 Qwen3-VL、GPT-4o/Claude API)见 [[LoRA打标#工具选型建议按场景2026|LoRA打标 §工具选型建议]]。

### 7. 面部精修是命门,手部不在数据集层死磕

- 真人 LoRA 对面部一致性要求极高(参数比动漫高 20–70%)。出图阶段用 [[FaceDetailer]]/ADetailer 二次修脸(1024 输出建议面部内部以 1536px+ 处理)。
- **手部**:ADetailer Hand 模型效果一般;主流做法是**出图后 inpainting 修手**(denoise 0.5),数据集只需保证手不严重遮挡脸。

## 预处理与质量门槛 / Preprocessing

- **分辨率**:SDXL/Flux 用 1024;SD1.5 用 512–768。原图尽量 ≥1024(可缩小不可放大),边为 64 倍数或开 ARB 分桶(bucketing)免裁剪;低清图先超分。
- **格式**:优先无损 PNG/TIFF;无水印/logo/文字;单人优先(多角色同框会混淆)。
- **流程**:收集去重(CLIP/DINOv2 嵌入 + 余弦相似度 0.90–0.95 聚类,每簇留一张)→ 人脸检测/方向校正 → 质量筛选 → 按**脸的大小**分 closeup/mid/fullbody 文件夹(驱动 repeat 权重)→ 裁剪分桶 → 打标人工复核。
- **少样本扩充技巧**:一张高清全身图可裁出"全身→七分身→半身→头肩→特写"多景别 + 标志道具(武器/吊坠/腰带扣)特写;镜像翻转可倍增样本,但**不对称特征(刘海方向/单侧疤痕/徽章文字)慎用**。

> [!tip] 近亲繁殖 / model collapse 防护
> 纯用 AI 生成图训 LoRA、再用它生成下一代会陷入自噬(输出趋同、罕见特征消失、细节退化;学界 Habsburg AI / MAD,Shumailov et al. *Nature* 2024)。**缓解**:expanding 数据循环(只增不替换)、混入真实参考图(哪怕少量也显著延缓崩坏)、合成比例经验阈值 ≤20%、每代严格人工筛选。
