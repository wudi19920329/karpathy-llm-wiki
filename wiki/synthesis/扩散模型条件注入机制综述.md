# 扩散模型条件注入机制综述(2024–2026)

## 摘要 / Summary

图像/视频生成里"怎么把条件(文本/参考图/结构/身份)塞进模型"的统一视角。两个范式转移已完成:**骨干 U-Net → Diffusion Transformer(DiT)**;参考图注入 **"独立 cross-attention" → "token 序列拼接(in-context)"**。统一抽象是**注意力注入**——差异只在:注入到哪一层、是否需训练、计算开销。

## 核心结论 / Key points

- **注意力注入统一一切**:文本走 cross-attention(或 MMDiT 联合注意力);参考图走 decoupled cross-attention([[IP-Adapter]])或共享 KV/self-attention;一致性/风格走 self-attention 共享(StyleAligned/MasaCtrl/ConsiStory/ReferenceNet);视频时序走 temporal attention。
- **训练 vs 免训练是关键工程取舍**:[[LoRA]]/IP-Adapter/[[ControlNet]] 需训练但稳定可复用;StyleAligned/MasaCtrl/ConsiStory/P2P 免训练即插即用但稳定性弱。生产常组合(IP-Adapter + ControlNet + LoRA)。

## 一、U-Net → DiT

- **U-Net**:下采样捕全局、跳跃连接恢复细节,卷积归纳偏置适合去噪,但难扩展到高分辨率/超大参数。文本走 cross-attention,结构走加性残差(ControlNet)。
- **DiT**(Peebles & Xie 2023):纯 Transformer 处理 VAE latent patch token,用 **adaLN** 注入时间步/类别条件;质量随 Gflops 单调提升(U-Net 不具备的可扩展性)。"仅改条件注入机制就能在 FID 上带来巨大差异"。
- **MMDiT**(SD3):图像/文本各用独立权重,仅在注意力时拼接做 **joint attention**(双向信息流,显著改善图文对齐尤其排版)。**FLUX.1** = 19 个 double-stream 块(分开权重)+ 38 个 single-stream 块(共享权重,attention 与 MLP 并行)。
- **token 化**:图像 VAE→patch token;视频 Sora 提"spacetime patches"、"图像=单帧视频";FLUX/HunyuanVideo 用 factorized 3D RoPE 按 (t,h,w) 索引。

## 二、文本/图像编码器分工

- **CLIP**(对比学习):擅长短语义/常见视觉概念,注意力更密集局部。
- **T5/MLLM**(纯文本大语料):擅长长文本/复杂指令,注意力更分散上下文化。
- 组合:SD3/3.5 用 CLIP-L + OpenCLIP-G + T5-XXL 三编码器;**FLUX 仅 T5 做序列文本、CLIP 仅做 pooled embedding 调制**;HunyuanVideo 用 decoder-only MLLM 替 T5(图文对齐更好)。
- 注入:文本 embedding 经 cross-attention(U-Net)或 token 拼接联合注意力(MMDiT);pooled 全局 embedding 经 adaLN/调制。
> 这解释了为何 **Flux 打标偏好自然语言**(走 T5)→ [[角色LoRA数据集构建#6. 打标铁律]]。

## 三、参考图机制(两代范式)

- **IP-Adapter**(Ye et al. 2023,核心 **decoupled cross-attention**):为图像特征单独加一组 K'/V',`Z' = Attn(Q,K,V) + λ·Attn(Q,K',V')`,仅训新增投影、base 冻结;**仅 22M 参数即可媲美全量微调**。轻量、可复用、与文本/ControlNet 兼容。λ 控图像影响强度。
  - 变体:IP-Adapter Plus(更细 token)、FaceID(人脸 ID embedding 替 CLIP + LoRA)、**InstantID**(ID embedding + decoupled cross-attention + IdentityNet 空间控制,单图零样本保身份且保文本可编辑)、PuLID。
- **ReferenceNet**(Animate Anyone):去噪 U-Net 的对称可训练副本,把参考特征拼进 self-attention 的 K/V,比 ControlNet 加性残差更能保细节,用于角色动画(MagicAnimate/MagicPose)。
- **DiT 时代 in-context 范式(2024–2025 最新)**:
  - **OminiControl**(NUS,ICCV 2025):复用 DiT 自身 VAE 编码条件图,条件 token 与图像 token 拼成统一序列由原 multi-modal attention 处理,仅 ~0.1%(FLUX 上约 0.4%)额外参数 + 动态位置编码;配套 Subjects200K 数据集。
  - **[[Flux-Kontext]]**(BFL 2025):"sequence concatenation"统一局部编辑与 in-context 生成,参考图经冻结 auto-encoder 编码成 context token + 3D RoPE 常数时间步偏移分离 context/target;**无独立 cross-attention**,代价是上下文窗口约 2× 计算但不增参数;LADD 蒸馏后 1024px 3–5 秒。
  - **FLUX IP-Adapter**(InstantX):全 57 块加图像注意力处理器,SigLIP 编码→128 图像 token,仍是 decoupled 求和(与 Kontext/Omini 纯拼接不同)。
- **视频参考图/首帧**:I2V 主流把首帧 latent 与噪声 latent **通道维拼接**(Wan/HunyuanVideo-I2V);ConsistI2V 用首帧时空注意力 + FrameInit。

## 四、LoRA(Low-Rank Adaptation)

- **原理**:冻结 W,学低秩增量 `ΔW = BA`(r≪d),仅训 A、B(预训练模型有低内在维度)。
- **vs 其他定制**:DreamBooth 全量微调(保真最高但每概念一个新模型);Textual Inversion 只学一个 token embedding(文件极小、保真有限);**LoRA 训练快、文件小、可分享叠加**——风格/角色/概念定制主流。耗时:DreamBooth-LoRA ~5 分钟 vs 免训练 ConsiStory TTCS 32 秒。
- **多 LoRA 融合**:LoRA Merge(线性加权,过多失稳)、ZipLoRA/LoRAHub(学系数)、Multi-LoRA Composition(LoRA Switch/Composite)、FreeFuse(注意力图自动 masking)。
- 视频 DiT(Wan/HunyuanVideo)同样支持 LoRA。
> 角色 LoRA 的训练落地 → [[Flux-LoRA-ai-toolkit训练实战]];数据集 → [[角色LoRA数据集构建]]。

## 五、注意力注入机制(重点)

1. **Cross-attention**:latent 作 Q、条件作 K/V;MMDiT 升级为联合注意力。
2. **Decoupled cross-attention**(IP-Adapter):图像单独 K'/V' 相加,文本/图像解耦可独立加权。InstantStyle 发现 SDXL 仅两层负责风格,只注入"风格块"即隐式解耦。
3. **Self-attention 共享(多免训练)**:MasaCtrl(mutual self-attention,目标 Q 查源 K/V)、StyleAligned(对 Q/K 施 AdaIN + 共享注意力保风格)、Reference-only ControlNet、ConsiStory(SDSA 跨帧共享主体 KV,约比当时 SOTA 快 20×)、StoryDiffusion(Consistent Self-Attention 长程故事)。
4. **Attention map 控制**:Prompt-to-Prompt(注入源 cross-attention map 实现免训练免 mask 编辑,结构早期步定)、Attend-and-Excite。
5. **视频时序注意力**:temporal attention(同位置跨帧)、full spatio-temporal(CogVideoX/HunyuanVideo)、causal/sparse;免训练:Text2Video-Zero、FateZero、Flatten/Fresco(光流引导)、TokenFlow、AnyV2V。
- **对比维度**:注入位置(cross/self/temporal)× 加权(λ 标量 / AdaIN / rank-1 / 注意力图缩放)× 训练 vs 免训练 × 计算开销(免训练增推理注意力计算;in-context 拼接约 2×)。

## 六、ControlNet(结构控制,作对照)

[[ControlNet]](Zhang et al. 2023):冻结 base、复制编码块为可训练副本,用 zero convolution(权重初始化为 0)连接,初期不破坏 base、逐步学边缘/姿态/深度/分割,加性残差注入。DiT 移植:FLUX ControlNet(XLabs/InstantX 复制少量 MMDiT 块)、BFL 官方 Depth/Canny-dev(全 12B 输入拼接,更重)、SD3.5 ControlNet(8B 级)。

## 七、机制组合

生产常组合:IP-Adapter(参考图/身份)+ ControlNet(姿态/深度)+ LoRA(风格/角色)+ 文本 prompt;InstantID = ID embedding + decoupled cross-attention + IdentityNet;角色动画 = ReferenceNet(外观)+ Pose Guider(姿态)+ temporal attention(时序)+ CLIP(语义)。**decoupled cross-attention 的"可加性"是这些组合成立的关键。**

## 选择建议 / Recommendations

- **保真角色/风格定制**:LoRA(需复用且可接受 ~5 分钟训练);要秒级零样本转免训练注意力共享(ConsiStory/StyleAligned)。
- **零样本身份保持**:U-Net 选 IP-Adapter/InstantID;**DiT/FLUX 选 in-context(Kontext/OminiControl)或 FLUX IP-Adapter**。
- **结构控制**:ControlNet;DiT 上 OminiControl(额外参数仅 ~0.1–0.4%)。
- **改变决策的触发**:骨干迁到 MMDiT/DiT → 放弃 U-Net 式 decoupled cross-attention 默认假设,优先 token 拼接(in-context,DiT 上更省参数);若推理延迟敏感 → 避免 Kontext 式上下文翻倍,改轻量 adapter。
