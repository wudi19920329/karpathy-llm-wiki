# 剧本到 AI 漫剧生产流水线

## 摘要 / Summary

把一部**原创剧本**做成 **AI 动态漫(motion comic)** 的端到端流水线:剧本 → 角色圣经/分镜 → 角色资产(LoRA)→ 批量出镜头 → 图生视频 → 剪辑装配。本页是**通用层**综合(原创,串联库内六页),把此前各自独立的"数据集 / 打标 / 训练 / 一致性出图"四块知识按生产顺序接成一条线;项目专属实例(角色表、逐镜清单)放各项目仓库,不进 wiki。

## 六阶段 / The pipeline

### S1 剧本 → 角色圣经 + 分镜脚本

- 从剧本提炼**角色圣经**:每角色的固定身份特征(脸/发/瞳/标志物)与**可变属性**(服装/状态/情绪)分开列——这个二分法直接决定 S3 打标的"省略 vs 标注"(见 [[LoRA打标]] 黄金法则)。
- 分镜脚本按镜头列:景别/角度/运镜/时长/画面/音效。**单镜 3-5s 为宜**(与主流 I2V 单段生成长度对齐);景别词写法遵循 [[Flux提示词-景别词排序规范]];景别/运镜术语底子见 [[AI视觉生成基础手册]]。
- ⚠️ 剧情道具会转移、角色状态会变化(如"某物件后期换了主人")——在圣经里**显式标记为可变**,否则 S3 会把它焊进角色。

### S2 角色圣杯图 + 设定表

- 按 [[ComfyUI-角色多镜头一致性工作流]]:先出**全身设定表**锁"脸+服装+配色+画风"四要素,固定 seed,FaceDetailer 精修脸(参数 → [[Detailer-采样参数调优]])。
- 出场少的配角**不训 LoRA**,走 PuLID / 指令编辑(阈值判断 → 一致性工作流页「何时切换策略」:单角色 <20-30 张不必训)。

### S3 数据集扩充 + 打标

- 扩充:每主角 15-30 张,张数比例特写:半身:全身 ≈ 4:3:3;从种子图用 Flux-Kontext / Qwen-Image-Edit **单步**生成各变体(链式编辑 ≤6 次防退化);角度/表情/光照/背景多样化——全套判据见 [[角色LoRA数据集构建]]。
- 打标:[[JoyCaption]] 自然语言模式(Flux/T5 友好),`触发词领头 + 自然语言句子`;**标注可变属性、省略身份特征**;caption 带画风类别词(anime illustration)保留改风格灵活度;**逐张人工复核**。工具选型 → [[LoRA打标]]。

### S4 角色 LoRA 训练

- ai-toolkit 24GB 基线:rank/alpha 16/16、adamw8bit、lr 1e-4、flowmatch、8bit 量化、1000-2000 步、每 250 步存档,XYZ 网格早停挑 checkpoint——全部参数与分歧调和见 [[Flux-LoRA-ai-toolkit训练实战]]。
- 二次元专项(画风词/叠 anime LoRA/rank 升 32)同页。

### S5 批量出镜头(静帧)

- 每镜 prompt = `触发词 + 场景/构图/光照/色板描述`;分镜里的**角色外貌全描述段替换为触发词短语**(LoRA 已锁身份,重复描述反而抢权重)。
- 角色 LoRA 0.8-1.0 + 风格 LoRA 0.3-0.8(总和 ≤1.2);Flux.1 用 euler+simple、guidance 3.5(**不用经典 CFG**)。
- 每镜 FaceDetailer 固定 seed;按分镜色板分场景统一校色;双人镜头用双 LoRA + 区域 prompt 或指令编辑合成。

### S6 动态化 + 装配

- **图生视频**:逐镜 I2V(如 Wan 2.x),3-5s/段,分镜的运镜词(推进/拉出/横移/环绕)映射到 I2V 运镜控制;>5s 长镜用尾帧续段;特殊运镜(希区柯克变焦)I2V 难出,用首尾帧插值或后期 2.5D 视差替代。
- **剪辑装配**:转场(黑场/闪白/溶解)、V.O. 对白、音效、音乐在剪辑软件完成——生成阶段只交付干净单镜头素材。

## 关键原则 / Principles

1. **一致性资产先行**:先花成本锁角色(S2-S4),再批量出镜头——顺序反了每镜都在漂移。
2. **打标决定 LoRA 的自由度**:S1 的"固定/可变"二分是全流水线最上游的决策,错了要重训。
3. **单镜短、镜头多**:动态漫靠剪辑节奏而非单段长视频;3-5s 单元化生成最稳。
4. **许可证**:Flux.1-dev 非商用,LoRA 继承限制;作品要商用需换底模或走授权(→ [[Flux-LoRA-ai-toolkit训练实战]] 开放问题)。
