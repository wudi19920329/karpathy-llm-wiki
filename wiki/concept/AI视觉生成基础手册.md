# AI 视觉生成基础手册

## 摘要 / Summary

从"文生图"到"图生视频"的全维度基础参考:**容器层**(像素/色彩/格式)+ **质感层**(构图/光影/色彩/透视/景别)+ **引擎层**(扩散模型/提示词)+ **时间层**(帧率/时序一致性/运镜)。核心论断:**时间一致性(temporal consistency)是当前 AI 视频最难的问题**。本页为结构化索引,技术原理深挖见 [[扩散模型条件注入机制综述]]。

## 第一部分:容器层(图像基础属性)

| 概念 | 要点 | 误区 |
|---|---|---|
| 像素/分辨率 | 细节天花板;偏离模型原生分辨率→构图崩(多头多肢)。SD1.5=512,SDXL=1024 | DPI 只对物理输出有意义,屏幕只认像素数;放大≠增信息 |
| 宽高比 | 1:1 / 16:9 / 9:16 / 4:3 / 21:9;生成时设定,别事后裁 | 非原生比例强生成→主体被裁/拉伸 |
| RGB / 色彩通道 | 加色模型;VAE 编码前 3×512×512,编码后 ~4×64×64 | 屏幕 RGB 直接送印刷不转 CMYK→偏色 |
| 色彩深度(位深) | 8-bit/通道=1670 万色;16-bit 渐变更平滑 | 宽色域+低位深→色带断层(banding) |
| 色彩空间/色域 | sRGB(网络,~35% 可见色)< DCI-P3 < Adobe RGB < Rec.2020(HDR) | Adobe RGB 不转就导出 sRGB→发灰 |
| 动态范围/HDR | Log 格式(ARRI/S-Log)灰扁保动态供调色;Luma Ray 3 支持原生 HDR EXR | — |
| 色温/白平衡 | 低色温暖(烛光 2000–3000K)、高色温冷(日光 5600K) | 调色软件"色温滑块"是校正量非实际色温 |
| 透明度/Alpha | PNG/WebP 支持,JPEG 不支持;多数文生图默认无透明通道 | — |
| 文件格式 | JPEG(有损照片)/PNG(无损透明)/WebP(现代通用,比 PNG 小 ~26%) | JPEG 反复保存累积失真 |

## 第二部分:质感层(美学维度,= AI 提示词"行话")

- **构图**:三分法/黄金比例(38.2%/61.8%)、三角(正三角稳/倒三角张力)、对角线(运动感)、对称、引导线/视线引导、框中框、前景遮挡、负空间留白、视觉重量与张力。AI 词:`rule of thirds` / `triangular composition` / `dynamic diagonal` / `frame within a frame` / `leading lines` / `negative space`。
- **层次感**:前景—中景—背景三层 + 大气透视 + 景深虚化。AI 词:`layered composition, foreground/midground/background separation, atmospheric depth`。
- **独特性**:视觉锚点(标志道具/配色/剪影)+ 不落俗套构图 + 克制配色(hex 锁定),让画面"一眼能认出"。
- **光影**:三点布光(主光 45°/辅光柔化/轮廓光分离),光比定戏剧性;伦勃朗光(暗侧脸颊三角光斑)。AI 词:`Rembrandt lighting` / `three-point lighting` / `rim light` / `golden hour` / `chiaroscuro`。
- **色彩和谐**:互补(橙-青)/类似/单色/三角/分裂互补;饱和度与明度同等重要。
- **色彩分级 vs 校正**:校正=技术还原(白平衡/曝光);分级=艺术造型(色轮 Lift/Gamma/Gain、LUT)。
- **透视**:一点/两点(街角建筑最常用)/三点(仰视虫眼/俯视鸟瞰)+ 大气透视。
- **焦距**:广角(14–35mm 透视夸张)/标准(50mm)/长焦(70–300mm 压缩+浅景深)/鱼眼。好莱坞镜头-景别:50mm≈中景、85mm≈近景、100–120mm≈大特写。
- **景深/虚化**:浅景深(大光圈 F2、长焦、近距)突出主体。AI 词:`shallow depth of field` / `bokeh` / `f/1.8` / `deep focus`。

### 19. 景别 / 镜头景别(Shot Size)

由远及近:大远景(EWS,定场)→ 远景/全景(WS,全身+环境)→ 全身景(Full Shot)→ 牛仔镜头(Cowboy,膝盖以上)→ 中景(MS,腰以上,对话)→ 中近景(MCU,胸/肩)→ 近景/特写(CU,满脸)→ 大特写(ECU,眼/唇)。
**镜头角度**:平视/低角度(显强大)/高角度(显弱小)/荷兰角(不安)/过肩(OTS)/鸟瞰。
> Flux 里景别词怎么排序、为何不能堆叠 → [[Flux提示词-景别词排序规范]]。

- **材质**:`brushed metal` / `silk fabric` / `subsurface scattering skin`。
- **渲染风格**:photorealistic / anime / oil painting / 3D render / Octane / Unreal Engine。

## 第三部分:引擎层(文生图技术原理)

- **扩散模型**:训练时加噪→纯噪声;生成时反向去噪。**潜空间扩散**(SD):VAE 编码(512×512×3→64×64×4,省 ~48×内存)→ U-Net 在潜空间迭代去噪(输入=带噪潜图+文本嵌入+时间步)→ 调度器算少噪潜图(20–30 步)→ VAE 解码→ CLIP 文本编码器给条件。**早期步定全局构图,后期步精修细节**。深挖架构(U-Net→DiT)→ [[扩散模型条件注入机制综述]]。

> [!warning] 矛盾 D-1:CFG 5–9 是经典 SD 的,**别套到 Flux**
> 本手册 §23:经典 **CFG 设 5–9(避免 >10 过饱和)**——这是 classifier-free guidance 的经典扩散口径。
> 但 **Flux 是 guidance-distilled,绝不用经典 CFG 7–8**:真 CFG=1 + distilled/Flux guidance ≈ 2.5–3.5(见 [[Flux-LoRA-ai-toolkit训练实战]] / [[ComfyUI-角色多镜头一致性工作流]])。
> **结论(模型相关,非真矛盾)**:经典 SD → CFG 5–9;Flux → CFG 1 + guidance 3.5。拿"5–9"套 Flux 会废。CFG 原理(Ho & Salimans 2022)详见 [[扩散模型条件注入机制综述]]。

- **种子/采样器/步数**:种子定初始噪声(固定可复现);采样器(Euler/Euler a/DPM++/DDIM);调度器(Karras 对数曲线低步数也保细节);步数太低不足、过高边际递减。
- **提示词工程**:正向顺序"内容类型→主体→风格→构图/光影/镜头";负面提示词(`bad anatomy, extra fingers, blurry, watermark`)主要作用在第 10 步后显现,用 5–10 个精准词而非堆砌;权重 SD 用 `(word:1.3)`、MJ 用 `::2`(Flux 无效);关联效应(高权重元素"传染"周边)需用权重/负面解耦。

## 第四部分:桥梁概念(静帧→运动)

- **帧率语言**:24fps(电影感)/25fps(PAL)/30fps(电视/社交)/60fps(运动,过滑=肥皂剧效应)/120fps+(慢动作)。"电影感"=24fps+180°快门(1/48s)产生恰当运动模糊,非帧率本身。AI 现状:Kling 30fps、Sora/Runway 24fps、Wan2.1 16fps(需 RIFE 插帧)。
- **关键帧/插帧(VFI)**:RIFE(IFNet 端到端估中间光流,比 SuperSlomo/DAIN 快 4–27×)是 AI 视频插帧事实标准。
- **光流(Optical Flow)**:相邻帧像素运动场;光流残差一致性常作视频稳定性指标。

## 第五部分:时间层(图生视频原理与镜头语言)

- **视频扩散两条路线**:(A)**3D U-Net**(SVD)——2D U-Net 插入时间卷积+时间注意力膨胀而来,空间层逐帧处理外观、时间层跨帧建运动,缺一不可;(B)**DiT**(Sora)——视频压成"时空块(spacetime patches)"token 序列,"图像=单帧视频",更易扩展。详见 [[扩散模型条件注入机制综述]]。
- **图像条件注入(img2vid)**:SVD 把条件帧加少量噪声→编码→均值沿时间轴复制拼接到 U-Net 输入。SVD 基础 14 帧、SVD-XT 25 帧、576×1024、2–4 秒;motion bucket id 控运动幅度(范围不同实现不一致)。
- **时序一致性**(最难):失效模式=闪烁/抖动/"沸腾"纹理/身份漂移/运动不连续。核心权衡:**提升一致性常牺牲细节与自然变化(稳定 vs 真实)**。对策:STG(免训练时空跳层引导,CVPR 2025)、两阶段流水线、平滑潜空间过渡。
- **主体一致性**:大模型可"涌现"物体永久性与单样本多镜头一致(纯规模产物);实务靠[[ComfyUI-角色多镜头一致性工作流|参考图条件/IP-Adapter/角色 LoRA]] + 分段生成。**误区**:提示词里描述外貌会与参考图信号打架→漂移。
- **运动物理**:玻璃破碎、流体/布料/毛发等"软物理"仍是各模型弱项,"运动中车里的一杯水"无模型通过。**物理理解是视频生成最难的未解问题**。
- **运镜语言**(AI 高价值词):摇(pan)/俯仰(tilt)/推拉(dolly,真实改变空间≠zoom)/横移(truck)/升降(pedestal)/跟(tracking)/环绕(arc/orbit)/升降臂(crane)/航拍/手持/滑动变焦(dolly zoom 眩晕)/跟焦(rack focus)。
- **叙事**:故事板规划景别序列(宽→中→近)、转场(cut/dissolve/match cut)、节奏(快切紧张/长镜沉静)、连贯性剪辑。
- **时长限制(2026-06)**:Kling 3.0 单次 10s、Seedance 2.0 15s、Sora 2 12s;**越短越稳,实务 3–6 秒最稳**。
- **编解码/码率**:H.264/H.265/VP9/AV1;帧率翻倍码率需成比例增加;24fps 压缩效率优于高帧率。
