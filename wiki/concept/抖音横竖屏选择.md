# 抖音横竖屏选择

## 摘要 / Summary

抖音画幅选型:**默认竖屏 9:16 保完播率,深度知识/电脑端演示例外走横屏 16:9**。资讯与工具分享类内容首选竖屏框架,电脑录屏用「竖屏背景 + 中间横屏录屏窗口」的混合形式兼顾清晰度与完播。

## 两种画幅特性 / Format traits

| | 竖屏 9:16 | 横屏 16:9 |
|---|---|---|
| 观感 | 全屏沉浸,视觉冲击强 | 画面小,需点开全屏,流失率略高 |
| 完播率 | 通常更高(符合刷抖音习惯) | 较低 |
| 信息容量 | 有限 | 大(PPT/屏幕录制/图表) |
| 气质 | 生活化、贴脸 | "专业",课程/纪录片质感 |
| 适合 | 人物出镜、口播、生活记录、剧情 | 知识讲解、教程演示、影视解说 |

## 资讯与工具分享的适配 / Routing for news & tool-sharing

- **资讯类 → 竖屏**:靠前 3 秒抓人,竖屏大脸出镜 + 大字标题留人;形态用真人口播或图文快闪。
- **工具分享 → 竖屏框架 + 嵌横屏录屏**:手机 App 演示天然竖屏直录;电脑端软件/网页工具用「竖屏背景 + 中间横屏录屏窗口」混合形式(目前主流),上下留白放标题和字幕重点。
- **例外用纯横屏**:① 电脑端深度教程,横屏录屏才看得清;② 想同步分发 B站/西瓜视频,横屏一份素材多平台用。

> [!note] 库内印证:对标账号的横屏选择
> [[对标账号-小白debug拆解]] 用**横屏 1080p 知识区长视频(5-10 分钟)**——看似与"资讯首选竖屏"相悖,实为落在「深度知识讲解 + 多平台分发」例外分支,与本页分流规则兼容,非矛盾。资讯快讯混剪(如本项目 9:16 竖版)与科普长视频(横屏)是两条不同产品线的画幅选择。
