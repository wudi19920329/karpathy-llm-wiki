# z-image-agent打标工程师

## 摘要 / Summary

一份把 LLM 固化成「专业 LoRA 打标工程师」的 **system prompt**([[agent角色]] 里的第一个角色),给 **z-image** 底模的角色 LoRA 数据集生成**标准化中文标签**。它把 [[LoRA打标]] 的黄金法则(标可变、省想绑定的)写成**不可违反的硬约束**:身份特征只绑触发词、绝不入标;可变元素用中文按固定字段顺序详述。本页记录这套约定,并按 wiki 既有基线标注三处分歧(中文打标 / 真名触发词 / 固定画质词)。

## 核心约定 / The convention

### 1. 绑定 / 可变 二分(黄金法则的硬操作化)

- **固定(只绑触发词,标签里绝不出现)**:脸型、五官、肤色、身材。
- **自由可变(必须中文详述,不得遗漏)**:景别/角度、构图、姿态、情绪神态、服装、配饰、道具、背景、灯光。

> 这正是 [[LoRA打标]] / [[角色LoRA数据集构建#6-打标铁律-flux-用自然语言没描述的会被绑定|角色LoRA数据集构建 §6]]「标注你想可变的;省略你想锁进触发词的」的一个**硬操作化实例**——把「不描述身份特征」从建议升级为「绝对禁止出现在标签任何位置」。呼应 [[JoyCaption]] 页的实测教训:VLM 罐头选项锁不住瞳色/发色,**必须用强指令**才真锁得住;这份 prompt 走的就是强指令路线。

### 2. 强制字段顺序

每张图标签严格按此序排列(「保证模型学习逻辑一致」):

```
触发词 → 景别/构图 → 姿态 → 情绪 → 服装 → 配饰 → 道具 → 背景 → 灯光
```

### 3. 触发词规则

- 每张图**以用户定义的触发词开头**,全程唯一;触发词后接「一个女孩,单人」。
- 与库内基线 `[trigger] woman, <描述…>`(见 [[Flux-LoRA-ai-toolkit训练实战#触发词]])的「触发词领头 + 类别词」一致。

### 4. 用词与画质规范

- **纯中文打标**,仅触发词可英文;词汇精准统一(如「挂脖上衣」全程不改口),忌冗余/主观评价(「非常好看的」「精致的」)。
- 每张图**结尾统一追加固定画质词**:`8k高清, 写实风格, 细节拉满`。

### 示例(prompt 内附)

```
diaochan, 1个女孩，正面角度，脸部特写，站姿，情绪平静，露肩, 上衣是紫色挂脖高领旗袍…蓝色蝴蝶发饰…墨绿色纯色背景, 棚拍柔光，8k高清, 写实风格, 细节拉满
```

## 与 wiki 基线的三处分歧(带基线+标注)

> [!info] B · 纯中文打标 —— 表面分歧,非真矛盾(按底模分流)
> 库内既有页几乎都是英文(Flux 走 T5 英文自然语言 / SD 走 WD14 英文 booru)。**中文打标不与之对撞**:z-image 是通义系原生中文底模,对中文语义/文本编码更友好,中文打标是 [[LoRA打标]]「按底模分语言」轴上的**一个合理分支**(z-image → 中文结构化;Flux → 英文自然语言)。用其它英文底模时,应回到英文方案。

> [!warning] E · 示例用真名 `diaochan` 作触发词 —— 与「不用真名」基线有张力
> wiki 基线(bghira / mnemic,见 [[角色LoRA数据集构建#6-打标铁律-flux-用自然语言没描述的会被绑定|角色LoRA数据集构建 §6]] 与 [[Flux-LoRA-ai-toolkit训练实战#触发词]])明确:**用罕见乱码 token(`p3rs0n`/`sh4d0wh34rt`)、不用角色真名**,以防 base 模型的同名先验漏入、污染学习。
> 这份 prompt 的触发词是「用户定义」的,`diaochan`(貂蝉)只是**示例**,并非强制;但示例恰用了一个知名角色真名。z-image 对貂蝉是否有强先验未知——**谨慎起见仍建议改用罕见 token**,别直接沿用示例里的真名。

> [!warning] F · 每图追加固定画质词 —— 对训练有效性存疑
> caption 里**每张都不变的词会像触发词一样被「烘焙」进模型**(不变的部分 = 被绑定;见 [[角色LoRA数据集构建]]「没描述/恒定的会被绑定」)。因此:
> - `8k高清`「细节拉满」这类恒定词对「可变」无帮助,基本是随触发词一起被吃进去的无效/近无效信号;
> - `写实风格` 恒定 = 把「写实」焊进角色。若整套数据集本就全写实、且不打算改风格,这符合意图;若想保留改风格的灵活度,应**移除画质/风格恒定词**。
> 这是 practitioner 惯例,**未见受控验证**;§2 的「固定字段顺序保证学习逻辑一致」同属无实证断言,当经验起点而非定论。
