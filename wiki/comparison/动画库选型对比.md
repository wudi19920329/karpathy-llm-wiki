# 动画库选型对比

## 摘要 / Summary

「做动画选哪个库」没有全场景最强——**Remotion 只在"程序化生成视频"这一场景是最优解**,其余动画类型各有专门工具。选型按目标产物(视频文件 vs 网页交互 vs 教学演示)分流,而非比功能多寡。

## 按场景分流 / Scenario routing

| 场景 | 首选 | 理由 |
|---|---|---|
| 程序化生成视频(数据驱动、批量、可版本控制) | **Remotion** | React 组件描述每一帧,渲染成真 mp4;生态成熟、有公司维护;适合年度报告/个性化批量视频/产品演示 |
| 代码讲解 / 教学演示动画 | **Motion Canvas** | 时间线基于 generator 函数,做「逐步演示」比 Remotion 直觉得多 |
| 数学 / 科学动画 | **Manim** | 3Blue1Brown 风格的事实标准 |
| 网页内交互动画(不导出视频) | **GSAP / Framer Motion / CSS** | Remotion 在此是杀鸡用牛刀 |
| 设计师主导的动效(导出到 web/app) | **After Effects + Lottie** | 设计工作流最成熟 |
| 3D 动画 | **Blender**(工具向)/ **Three.js**(代码向) | Remotion 可嵌 Three.js 但只是渲染管线 |

> [!warning] Remotion 许可费
> Remotion 对**公司使用收许可费**(个人和小团队免费),商用变现前须纳入合规成本核算——与 [[抖音科普视频生产流水线]] 的「Flux.1-dev 非商用」同属变现前合规项。
